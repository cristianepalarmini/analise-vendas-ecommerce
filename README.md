# 📊 Análise de Vendas e E-commerce

Projeto de análise de dados de vendas desenvolvido com **Python, SQL e Power BI**, com foco na análise de faturamento, lucro, pedidos e desempenho comercial.

## 🎯 Objetivo

Analisar dados de vendas de um e-commerce para identificar padrões de desempenho, acompanhar indicadores comerciais e transformar dados em informações úteis para tomada de decisão.

O projeto simula um cenário empresarial e utiliza dados fictícios para demonstrar um fluxo completo de análise de dados.

## 📌 Principais indicadores

- Total de pedidos
- Faturamento total
- Lucro total
- Ticket médio
- Taxa de pedidos concluídos
- Faturamento por categoria
- Faturamento por canal
- Faturamento por região
- Faturamento ao longo do tempo
- Lucro por categoria

## Análises realizadas

O projeto permite analisar:

- Quais categorias apresentam maior faturamento;
- Quais canais geram maior volume de vendas;
- Como o faturamento se distribui entre as regiões;
- Como o faturamento evolui ao longo do tempo;
- Quais categorias apresentam maior geração de lucro;
- Qual é o ticket médio dos pedidos;
- Qual é a proporção de pedidos concluídos.
