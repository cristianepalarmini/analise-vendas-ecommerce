# Análise de Vendas e E-commerce

## Objetivo

Analisar dados de vendas de um e-commerce para identificar padrões de faturamento, lucro, comportamento de vendas e desempenho por diferentes dimensões.

## Indicadores analisados

- Total de pedidos
- Faturamento total
- Lucro total
- Ticket médio
- Taxa de pedidos concluídos
- Faturamento por categoria
- Faturamento por canal
- Faturamento por região
- Produtos mais vendidos
- Faturamento mensal

## Perguntas de negócio

- Qual é o faturamento total?
- Qual é o lucro gerado pelas vendas?
- Qual é o ticket médio?
- Qual categoria apresenta maior faturamento?
- Qual canal apresenta maior faturamento?
- Qual região apresenta maior faturamento?
- Quais são os produtos mais vendidos?
- Como o faturamento evolui ao longo do período?

## Tecnologias

- Python
- Pandas
- SQL
- Power BI
- GitHub

## Etapas da análise

1. Organização da base de dados
2. Análise e tratamento utilizando Python e Pandas
3. Criação de consultas SQL
4. Cálculo dos principais indicadores
5. Construção do dashboard no Power BI
6. Interpretação dos resultados

## Dados

Os dados utilizados são fictícios e foram criados exclusivamente para fins de estudo e demonstração de habilidades em análise de dados.
